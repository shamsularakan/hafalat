## اختبارات إضافية خارج قائمة AC
- المصادقة: تجزئة scrypt، رفض مكرر/قصير، انتهاء/إبطال جلسة، دخول خاطئ، تطبيع أرقام دولية، قبول تفويض معلق (tests/auth.test.ts).
- الباقات: حدود مجانية (مناسبة/30 ضيف/مفوّض)، ترقية stub تفتح الحدود، عضو لا يفوتر (tests/plans.test.ts).
- التصميم والوسائط: إصدارات مسودة/نشر، رفض عنوان/لون غير صالح، حقوق صوت إلزامية، رفض SVG/تنفيذيات، صوت مربوط برمز صالح، حذف يمنع الوصول (tests/design-media-backup.test.ts).
- العزل: مفوّض لا يرى ضيوف غيره ولا يعدلها (tests/isolation.test.ts).

## فحوص هندسية
- `npm run typecheck` — TypeScript strict نظيف.
- `npm run build` — بناء إنتاجي ناجح لكل المسارات.
- CI: GitHub Actions يشغّل typecheck + tests + build + migrations على Node 24.
