# هوية ليلتنا البصرية (تطبيق حرفي من واجهة الشاشات الصغيرة)

## لوحة الألوان المعتمدة (`src/app/globals.css`)
| العيّنة من الصورة | القيمة | الاستخدام |
|---|---|---|
| فاتح | `#EDE9E6` | الخلفيات العامة/البطاقات |
| كريمي جدًا | `#FBF8F5` | خلفية الصفحة/النصوص على الداكن |
| ذهبي نحاسي | `#C99A6B` | الأزرار الأساسية، الشعار، التمييز |
| بني داكن | `#5A4A44` | العناوين والترويسات |
| بني أغمق | `#4A3B36` | الخلفيات الداكنة/الـ Hero |
| أخضر | `#4F6B5F` | النجاح/اللوحات المالية |

الأسماء القديمة (`navy-*`, `lime-*`, `ivory*`) ما زالت مستخدمة في المكوّنات لكنها **معاد تعريفها** إلى قيم الهوية الجديدة — لا حاجة لتعديل كل مكوّن.

## الخط
`Thmanyah Serif Display` للعناوين، `Thmanyah Serif Text` للنصوص الرسمية، `Thmanyah Sans` للواجهة — تُحمّل فقط من ملفات مرخصة (`public/fonts/thmanyah`) عند توفرها؛ البديل الحالي Amiri/Noto/نظام عربي آمن.

## الشعار
`src/components/brand.tsx` — قوس + نخلة + كلمة «ليلتنا» و LAYLATNA، مطبّق في:
الصفحة الرئيسية، تسجيل الدخول، إنشاء الحساب، لوحة التحكم (جانبي وجوال)، صفحة الضيف/الخطأ.

## الشاشات المضافة (الصفحات غير الموجودة سابقًا)
| الشاشة | المسار |
|---|---|
| شاشة البداية + التعريف بالمزايا + الدعوات + المتابعة (4 شرائح) | `/onboarding` |
| تسجيل الدخول (بما فيه Apple/Google) | `/login` |
| إنشاء حساب | `/register` |
| بوابة الحضور/اختيار المناسبة | `/app/attendance` |
| الإحصائيات الشاملة | `/app/statistics` |
| المزيد (شبكة كل الأقسام) | `/app/more` |
| تفاصيل المورد (تواصل + عقود + مصروفات + تعديل) | `/app/events/[id]/vendors/[vendorId]` |
| بيانات المناسبة/تعديل | `/app/events/[id]` + حوار التعديل |
| اختيار قالب التخطيط | مركز التخطيط `/plan` |
| قائمة التجهيز/المهام/الميزانية/المدفوعات/الموردون/الجدول/الفريق/الإغلاق | مسارات `/app/events/[id]/*` |

## الشريط السفلي للجوال (مطابق للصورة)
`الرئيسية · مناسباتي · الحضور · الإحصائيات · المزيد` — مع مساحة آمنة لأجهزة iPhone.

## الترحيل
`db/migrations/003_identity.sql` يحدّث قوالب الدعوات والتصاميم المخزنة إلى اللوحة الجديدة (idempotent).
