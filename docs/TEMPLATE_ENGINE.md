## غير منفذ بعد / مرحلة لاحقة
- تصدير **PNG/PDF** من النسخة المعتمدة (يُضاف عبر خدمة تصيير أو canvas side؛ حاليًا طباعة المتصفح للتذكرة).
- فيديو **MP4** عبر خدمة تصيير مستقلة (خارج نطاق الخادم الحالي).
- سحب وإفلات فعلي (Drag & Drop) على الـ Canvas — حاليًا تحرير رقمي/نموذجي للطبقات عبر لوحة الخصائص.
- مزامنة مكتبة القوالب المدفوعة مع بوابة الدفع (الحقول `is_premium` جاهزة).
- اختبارات أتمتة على Safari فعلي (المختبر آلي عبر Chromium).
